# Christian Jay Javal | QA & Software Testing Portfolio

Personal portfolio website of Christian Jay Javal, a QA professional with 12 years of experience in software testing, currently building Playwright automation skills.

**Live site:** [cjayjaval.github.io](https://cjayjaval.github.io)

## What's on the site

- **About:** background, work preference and the types of projects I've tested
- **Experience:** work history from 2014 to today
- **Portfolio:** a sample website testing report, a sample Jira-style bug report, and two Playwright projects
- **Skills:** testing, automation, tools and ways of working
- **Services:** areas where I can help a team
- **Contact:** email, LinkedIn, GitHub and a downloadable résumé

The sample report and bug report use a fictional website and made-up data.

## Playwright projects

- [playwright-ecommerce](https://github.com/cjayjaval/playwright-ecommerce): end-to-end tests for login, cart, checkout, coupons and order history
- [playwright-event-booking](https://github.com/cjayjaval/playwright-event-booking): end-to-end tests for creating and booking events

## Built with

Plain HTML, CSS and a little JavaScript in a single file. There is no framework and no build step. It is hosted for free on GitHub Pages.

## Files

| File | Purpose |
|---|---|
| `index.html` | The whole website |
| `Christian_Jay_Javal_Resume.pdf` | The résumé behind the "Download résumé" button |
| `README.md` | This file |

## Run it locally

Download or clone the repository and open `index.html` in a web browser.

## Update the site

1. Edit `index.html`, or upload a new copy with the same file name.
2. Commit the change to the `main` branch.
3. GitHub Pages republishes the site within a couple of minutes.

The résumé file must keep the exact name `Christian_Jay_Javal_Resume.pdf`, or the download button will stop working.

## Versions

Versions follow the `MAJOR.MINOR.PATCH` format, for example `v1.0.0`. Each one is listed on the [Releases](../../releases) page.
